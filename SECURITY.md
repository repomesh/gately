# Security Policy

## Supported versions

Security fixes are released for the latest version only. Please upgrade to the latest release before reporting.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

- Preferred: use [Report a vulnerability](https://github.com/wangwanjie/gately/security/advisories/new) on the repository's Security tab (GitHub private vulnerability reporting).
- Alternatively, email **vanjay.dev@gmail.com**.

Include the affected version, how Gately is deployed, reproduction steps or a proof of concept, and the impact you observed.

## What to expect

- An acknowledgement within a few days.
- Once the issue is confirmed, the fix is developed in a private fork, and the reporter is invited to verify it.
- The fix is released together with a GitHub security advisory. A CVE is requested through GitHub when applicable, and reporters are credited unless they prefer otherwise.
