# Gately v0.6.1.1 發布

2026 年 10 月 30 日

[下載 v0.6.1.1](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.1.1)

## Web 路徑探測封鎖

入侵防護的規則來源新增「Web 路徑探測」，直接統計 Web 服務處理的請求，不讀取日誌：

- 可限定一個或多個監聽，留空表示全部；路徑規則支援萬用字元（`*` 也匹配 `/`，不區分大小寫）與 `~` 開頭的正規表示式，`//.env`、`/a/../.env` 這類寫法依正規化後的路徑同樣命中；
- 預設只統計 404 與 444，存取正常頁面的請求不計數；可改為統計「任意狀態碼」（需搭配路徑規則），或「只統計未知網域」；
- 內建三個範本：Web 誘餌路徑（`/.env`、`/.git`、`wp-login.php`、`phpinfo.php`、phpMyAdmin 等，命中 1 次即封鎖）、未知網域掃描（1 分鐘 5 次）、Web 404 探測（1 分鐘 10 次）；
- 次數、時間視窗、封鎖時長、白名單、遞增封鎖與 nftables 同步與其他規則共用，任一監聽觸發的封鎖對全部服務生效。

Web 服務監聽卡片上的「路徑探測封鎖」會預選該監聽並套用誘餌路徑範本；編輯規則時可貼上請求路徑測試。詳見 [入侵防護 · Web 路徑探測](/zh-TW/docs/modules/guard)。

## 認證使用者頁面

側邊欄「Web」分組新增「認證使用者」頁面，集中管理共用使用者、單一登入網域、自助修改密碼與 OIDC 身分提供者，並依監聽列出站台，可篩選、全選後批次設定哪些站台使用共用使用者：未開啟驗證的站台勾選後同時開啟網頁驗證；只靠共用使用者驗證的站台不能在這裡取消，避免誤變為公開；使用轉發認證的站台不能勾選。全部修改按「儲存」後一起生效，任一項校驗失敗都不儲存。API 為 `GET/PUT /api/webservice/users`。

## 共用使用者自助修改密碼

「認證使用者」頁開啟「自助修改密碼」後，共用使用者（含透過內建 OIDC 登入應用程式的使用者）可在 `/__gately_auth/password`（簽發者網域為 `/__gately_oidc/password`）輸入目前密碼與動態驗證碼後修改密碼，各站台工作階段隨即失效。檔案服務共用使用者在「檔案共用使用者」頁另有開關，在同一頁面修改，明文或 bcrypt 的儲存方式保持不變，WebDAV、FTP、SMB 立即使用新密碼。錯誤次數與登入共用限流和自動封鎖；同一帳號 1 分鐘內只能修改一次。詳見 [Web 服務 · 自助修改密碼](/zh-TW/docs/modules/web#self-service-password)。

## 拒絕時中斷連線

站台「安全」頁新增「拒絕方式」：選擇「中斷連線」後，被封鎖、IP 存取控制（含路徑規則）或國家過濾拒絕的請求不傳回任何內容，存取日誌記為 444，可搭配白名單實現「自家 IP 正常存取、其餘一律中斷」。限流與 WAF 攔截不變。文件同時寫明中斷連線的邊界：TCP 與 TLS 交握已完成，HTTP/2、HTTP/3 只重設該請求，想對掃描器隱藏連接埠需要入侵防護封鎖。

## Cloudflare 通道路由規則

權杖通道填寫選填的 Cloudflare API 權杖後，卡片上的「路由規則」可直接讀寫通道的遠端設定：主機名稱、路徑正規表示式、服務，以及「不驗證回源憑證」和回源 Host 標頭，執行中的 cloudflared 無需重新啟動即生效；儲存時核對設定版本，避免覆蓋別處的修改；可為主機名稱建立開啟代理的 CNAME 記錄，已有記錄保持原樣並列出。詳見 [Cloudflare 通道 · 路由規則](/zh-TW/docs/modules/tunnels#cloudflared-ingress)。

## 日誌「不包含」篩選

日誌檢視器新增「不包含」輸入框，包含其中任意一個詞的日誌不顯示，與關鍵字同時生效；日誌 API 對應新增 `exclude` 參數。

## 修復與改進

- 誘餌連接埠與掃描偵測選擇永久封鎖時儲存失敗（#41）；
- 路由規則：服務位址結尾單獨的 `/` 自動去掉（cloudflared 會拒絕帶路徑的服務）；本機設定檔管理的通道儲存前需確認；指向通道但未開啟代理的 CNAME 依衝突回報；只在通道所屬帳號下尋找網域；
- Web 服務全域設定對話框不再提交共用使用者與 OIDC 設定，不會覆蓋「認證使用者」頁剛儲存的修改；
- 路徑探測依訪客請求的原始路徑匹配（重寫規則不再影響統計），存取日誌同樣記錄原始路徑；超長路徑只取首尾參與匹配，封鎖原因跳脫換行等控制字元；
- 自助改密儲存失敗時頁面只顯示統一提示，詳細原因寫入日誌；
- API 文件中部分多段說明出現中外文混排的問題。

## 升級提示

- Docker 拉取新映像後重建容器；OpenWrt 覆蓋安裝新的 `.apk` / `.ipk`；飛牛在應用中心手動安裝新版 `.fpk`；其他部署方式可在「系統設定」中線上升級。
- 已儲存的「任意狀態碼、無路徑規則、不限未知網域」的路徑探測規則會在下次編輯儲存時被拒絕，請補充路徑規則。
